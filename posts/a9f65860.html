Spring Boot 4 + Vue 3 整合 SSE 实现实时消息推送

一、引言

在现代 Web 应用中，实时消息推送已成为不可或缺的能力——无论是社交平台的即时通知、电商系统的订单状态更新，还是监控系统的实时告警。WebSocket 虽然功能强大，但在单向推送场景下显得过于”沉重”。

SSE（Server-Sent Events） 提供了一种基于 HTTP 协议的轻量级单向推送方案，客户端通过持久连接自动接收服务端推送的数据流，无需客户端轮询，也无需引入额外的协议和框架。

本文将使用 Spring Boot 4.x + Vue 3（Vite + Composition API + TypeScript）构建一套完整的 SSE 实时推送方案。

二、技术选型

层级 技术 版本
后端框架 Spring Boot 4.0.x
JDK Java 21+
构建工具 Maven 3.9+
前端框架 Vue 3.5+
构建工具 Vite 6.x
语言 TypeScript 5.x

SSE 工作原理

  • 客户端发起一次 HTTP GET 请求
  • 服务端保持连接不关闭，响应 Content-Type: text/event-stream
  • 服务端随时向客户端推送数据，格式为 data: <内容>\n\n
  • 连接断开后浏览器会自动重连

七、生产环境注意事项

7.1 连接数管理

  • 设置合理的超时时间：过短会导致频繁重连，过长会占用服务端资源
  • 连接数上限：SSE 每个连接占用一个线程（或虚拟线程），需评估服务器承载能力
  • Java 21 虚拟线程：在 Spring Boot 4.x 中启用虚拟线程可大幅提升并发连接数

八、总结

对比维度 SSE WebSocket 轮询
通信方向 服务端 → 客户端 双向 客户端 → 服务端
协议 HTTP WS/WSS HTTP
实现复杂度 低 中 低
浏览器支持 原生 EventSource 原生 WebSocket 无
自动重连 内置 需手动实现 不适用
适用场景 通知、日志、行情 聊天、协作、游戏 低频状态查询

SSE 是对 WebSocket 的有效补充——当你只需要服务端向客户端单向推送数据时，SSE 是更简单、更轻量的选择。结合 Spring Boot 4.x 的虚拟线程支持和 Vue 3 的 Composition API，可以快速构建出高性能的实时消息推送系统。
